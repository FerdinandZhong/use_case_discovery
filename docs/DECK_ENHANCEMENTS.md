# Deck Enhancement Brief — AI Discovery Workshop

_Proposed changes to `AI Discovery Workshop.pdf` (Vish's deck) to make it **room-first /
survey-optional**. This is a review brief; on approval I'll render the new/revised slides as a
Cloudera-branded PPTX addendum (`AI_Discovery_Workshop_Addendum.pptx`)._

## Why
Field reality: customers usually don't return the pre-survey and only open up in the in-person
session. The current deck's arrow runs pre-survey → matrix → canvas, which quietly assumes pre-data.
The fix is framing, not a rewrite: **the survey is an accelerant; the room is the primary data
source.**

## Revisions to existing slides
- **Slide 3 (Runbook — What it is / is NOT):** add a bullet — *"Works with or without a returned
  survey. If the survey is empty, the session itself IS the discovery."*
- **Slides 5–9 (Pre-Discovery Homework):** add a banner/callout — *"Best-effort, not a gate. Expect
  many customers to skip it and share only in the room."* Keep the question content (it becomes the
  facilitator's live question bank).
- **Slide 10 (Workshop Participants):** strengthen the **Executive Sponsor** line — *"Required: sets
  the North Star. No sponsor → reschedule."* Add *"SMEs are your richest source when there's no
  survey."*
- **Slide 11 (Workshop Mechanics):** relabel **Phase 2** as *"Problem Mining — this replaces the
  survey when there's no pre-data."*

## New slides to add
1. **"Two ways in: survey-fed vs room-first."** A simple 2-column visual — *Survey returned* (pre-fill
   dashboard, generate pack, review) vs *No survey* (live elicitation → capture → score in the room).
   Message: same destination, the tool adapts.
2. **"The room is the data source — live elicitation toolkit."** Three techniques: **Day-in-the-life**,
   **Silent-write → round-robin**, **Hypothesis use cases to react to**. When/why each.
3. **"Peel the onion, live."** Reframe slide 12's four question categories as a facilitator script for
   Phase 2 (ask order + follow-ups), not a survey form.
4. **"Close with a data ask."** New Phase-5 emphasis: MVP + RACI **+ a concrete data request with a
   date**. Converts room energy into a follow-up obligation; the #1 miss in no-survey sessions.
5. **"The cockpit tells the story."** The four linked phases as one journey —
   Dashboard → Prioritize → AI Canvas → Roadmap & RACI — numbered and checked off as you go, with
   one use case kept in focus across tabs ("Next" carries the baton). Mirrors the shipped app.

Match the deck: Cloudera navy `#1a1a4e`, orange `#EA2A0C`, sans-serif, sparse text, one idea per
slide, hand-drawn-ish accents where the original uses them.
